# Tabula. Galería de arte contemporáneo

Sitio web de una galería de arte ficticia que acerca la experiencia de ver y comprar arte a nuevos coleccionistas.

Trabajo educativo realizado para ORT Argentina, materias **Desarrollo II + Programación I (2da pre-entrega: maquetado y Bootstrap personalizado).

## Equipo

- Camila Cabanellas
- Ana Clara Razzetti

## Páginas

- `index.html`: inicio
- `quienes-somos.html`: quiénes somos
- `productos.html`: obras con filtro por categoría y carrito
- `servicios.html`: servicios y preguntas frecuentes
- `contacto.html`: datos, formulario, mapa y video

## Tecnologías

- HTML5 y CSS3
- Bootstrap 5.3.3 (personalizado en `css/styles.css`)
- JavaScript y jQuery 3.7.1
- Isotope 3.0.6 (filtro de obras)
- Google Fonts: DM Sans y EB Garamond

Las librerías están guardadas en la carpeta `assets/`.

## Estructura

```
assets/   librerías (Bootstrap, jQuery, Isotope)
css/      styles.css (estilos propios que pisan a Bootstrap)
js/       main.js, productos.js, carrito.js, formulario.js
img/web/  imágenes optimizadas para la web
```

## Créditos

- Íconos: SVG en línea basados en [Feather Icons](https://feathericons.com) (licencia MIT).
- Imágenes: generadas con inteligencia artificial, principalmente con Nano Banana.
- Tipografías: [Google Fonts](https://fonts.google.com).
- Librerías: [Bootstrap](https://getbootstrap.com), [jQuery](https://jquery.com) e [Isotope](https://isotope.metafizzy.co).

Todos los nombres de obras, artistas, precios y datos de contacto son ficticios.
